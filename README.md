# Stratos Weather App
Stratos is a sleek, responsive, and real-time weather dashboard that provides users with essential meteorological data, including hourly forecasts and 7-day outlooks. It is built as a single-file application using HTML, CSS, and vanilla JavaScript.  

# Features

Live Weather Updates: Get real-time data for any location.  Detailed Forecasts: Includes 7-day outlooks and hourly breakdown.  
Customizable UI: Choose between three distinct layouts (Atlas, Terminal, Minimal) and multiple accent colors.  
Theming: Integrated light and dark mode support.  
Persistence: Your saved locations are stored securely in your browser's local storage.  
Dynamic Visuals: Features animated weather icons and a dynamic sky canvas.  
Technical Stack Frontend: Pure HTML5, CSS3 (with custom properties for theming), and vanilla JavaScript.
